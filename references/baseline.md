# Reference anchor — `baseline` variant

## Anchor: Edward Tufte — marginalia as outer-margin running index

The defining move: the 16 numbered markers `(1)` — `(16)` in George's Personal Statement don't live inline with the text. They live as **marginalia in the outer margin** (the wider, 1.25in outer margin in the book's recto/verso layout).

Each marker in the margin:
- Set in a small sans (Inter or Work Sans, 8pt)
- Aligned to the baseline of the first line of the sentence it refers to
- Includes the marker number AND a 3–5 word gloss from the matching Definition in ELEMENTS Sample 1

Example:
```
                              |   (1)  Building creative
                              |        projects
The main text flows here in    |
a 60-68 character measure,    |
and when sentence (1) — the   |   (2)  Hands / imagination
one about putting together    |        to create
creative projects — is        |
cited, the marker floats in   |
the outer margin opposite.    |
```

This is Tufte's core marginalia pattern from *The Visual Display of Quantitative Information* and *Envisioning Information*.

## Other Tufte moves

- Small multiples if we have multiple IPP elements → could treat the 7 satellites as a sparkline-like grid
- No chart-junk — flat, direct
- Serif body (Source Serif 4 or EB Garamond)
- Sans marginalia (Inter, small)
- Folios in the outer top corner — subtle

## Your job

Produce a book where marginalia does structural work. The outer margin is not empty — it holds the running index of numbered markers with their Definitions-page glosses. The inner text is set calmly, no bold numerals interrupting the flow.

## IPP treatment

A single small-multiples grid: 7 satellites laid out as equal-sized text blocks in a grid, with a central block for Essential Motivation, arrows as thin 0.5pt strokes. All on a 13pt baseline grid. No boxes.

## Numbered markers

MARGINALIA ONLY. Do not set `(N)` inline in the text. The whole point of the variant is that markers live in the margin.

## Ban list

- No bold inline numerals in text
- No boxes on the IPP
- No color at all — this is a single-ink book
- No centered layouts except on the cover
