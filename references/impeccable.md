# Reference anchor — `impeccable` variant

## Anchor: Pentagram / Harry Pearce — Phaidon annuals, title-page architecture

- Massive, confident display type on chapter openers (100–140pt+)
- Asymmetric compositions — heading pushed to a grid edge, white space doing structural work
- Title pages treated as typographic compositions in their own right, not metadata pages
- Tight tracking on display type; loose tracking on small caps
- Section numbers as design elements (e.g. big "06" sitting beside chapter title)
- Body in a workhorse serif, headings in a complementary sans or a second serif at scale
- Cover: a single typographic statement. The text itself is the image.

## Skill stack — impeccable, FULL

Read these in order:

1. `~/.agents/skills/impeccable/SKILL.md` — shared design laws
2. `~/.agents/skills/impeccable/reference/brand.md` — this is a brand (book) register, not product

Pull every rule about:
- OKLCH color, neutral tinting toward brand hue
- Hierarchy via scale + weight (≥1.25 ratio; use 1.333 per BRIEF)
- No gradient text, no glassmorphism default, no hero-metric templates
- No em-dashes in copy (note: impeccable bans em-dashes in UX copy; in book body text we use them correctly. Don't over-apply this rule.)
- The AI slop test — no purple/pink gradients, no nested cards, no bento grids

## Your job

Produce a book that feels like Pentagram set the type. Asymmetric chapter openers. A single, confident accent color applied to one element on every spread. Display type doing the heavy lifting on every opener.

## IPP treatment

Radial grid with single-weight strokes (0.5pt), center typeset in display weight, satellites in body weight, arrows as thin triangular heads — typographically drawn, not image-imported.

## Numbered markers

Small-caps numerals in sans. `(1)` in small Inter caps tight against the start of the cited sentence.

## Ban list

Same as BRIEF's hard bans, plus: no centered layouts (use asymmetric), no boxed anything, no serif small caps (if using small caps, set them in the sans).
